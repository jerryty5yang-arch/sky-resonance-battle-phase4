# 測試關卡多部位 Boss / 後端 v32

僅更新 skytest「雲海防衛戰・測試關卡」的單人與雙人模式。正式關卡、既有技能數值、歌姬規則、排行榜排除、140–150 秒撤離及150秒Boss登場保留。

- 獵隼 HP：單人48／雙人72（原值×0.8）。
- 雷翼指揮官：800／1200 HP，機體上方名稱及10格血條。
- 雨燕：同波分成最多3機的 V字或直列編隊，分批入場，維持53台固定敵機總數。容量不足時整組延後。
- 雷雲：攻擊前0.65秒蓄能燈；獵隼／幻影：方向殘光；各機體：短暫受擊碎光。

## 雷霆守衛
核心3000／5100 HP；左右砲台各400／600 HP，獨立受擊、鎖定、暈眩及血條。翼砲台視為精英部位，破壞獲得300分，停止該側新攻擊、保留殘骸與黑煙；已發射彈幕繼續存在。僅核心擊破通關，砲台無需全毀。

第一階段：左右砲台交替攻擊（左5發扇形、右3發瞄準），核心鎖定後預警0.8秒、直線雷射1.2秒、恢復空檔1.2秒；定期召喚雨燕。
第二階段：核心HP≤50%切換，若正在雷射則中止並重新循環。左右擴大扇形分別9／7個射線位置，略去中央射線，保留中央安全間隙。預警0.8秒涵蓋掃射軌跡，雷射1.6秒，左右交替掃射。每輪雷射後2秒核心裝甲開放，期間停止Boss新攻擊／召喚；核心判定半徑46→58，原傷害倍率不變，無額外增傷乘數。召喚混合雨燕及獵隼。

雷射採連續亮青色光束、白色內芯及青色電弧，傷害仍為既有單次20與1.5秒受擊無敵。光束由相接區段組成，既有清彈技能可清除接觸區段，該輪不會補回；判定與顯示都使用同一組座標。雙人各自判定，不會因第一人受擊而替第二人消除光束。

Boss本體沿用已核准圖像，由程式分離砲台及核心裝甲動畫，未新增背景美術或GLB。
